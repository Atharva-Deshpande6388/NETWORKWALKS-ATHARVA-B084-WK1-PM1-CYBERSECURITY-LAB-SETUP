# WK1-PM1 Task Scope

**Reference used:** `WK1-PM1 — Week 1 — Project Module 1: Lab Setup VirtualBox and Kali Linux` (provided task sheet).

The task sheet asks for a VirtualBox-based cybersecurity practice environment with Kali Linux as the testing machine, a custom `NATNetwork` using `10.0.0.0/24`, Kali at the static address `10.0.0.2/24`, and Internet access. It also specifies enabling clipboard/file drag-and-drop integration and sharing the host's `/downloads` folder with the VM.

The setup and validation documented in this repository cover the VirtualBox installation, Kali VM launch, NAT Network and addressing configuration, gateway and external connectivity, DNS resolution, Nmap availability, snapshot creation, and post-snapshot connectivity checks.

**Evidence scope:** The supplied screenshots do not show the dedicated Shared Clipboard/Drag'n'Drop controls or a mounted `/downloads` shared folder. This repository therefore does not claim separate screenshot-based verification of those UI settings. Their absence from the evidence gallery should not be interpreted as a failure of the network configuration; those settings simply are not demonstrated by the supplied captures.
